# Realmora – Gemeinschaftsdaten

Hier können Spieler Daten aus **RealmoraTrace** einsenden, dem freiwilligen Zusatzaddon für **Realmora – Adventure Companion** (WoW Forever).

**So geht's:** Im Spiel `/rtrace export` eingeben, Text kopieren und hier über **Issues → New issue → „Daten einsenden“** einfügen.

Die Einsendungen werden geprüft, zusammengeführt und kommen mit der nächsten Realmora-Version zu allen Spielern zurück.
Enthalten ist nur Welt-Wissen (NPC-Orte, Questgeber, Beute, Belohnungen, Händler- und Lehrerangebote), kein Name, kein Realm, kein Konto.

---

Players can submit data from **RealmoraTrace**, the optional companion add-on for **Realmora – Adventure Companion** (WoW Forever).

**How:** In game type `/rtrace export`, copy the text and paste it here via **Issues → New issue → "Submit data"**.

Submissions are checked, merged and shipped back to everyone with the next Realmora version.
Only world knowledge is included (NPC locations, quest givers, loot, rewards, vendor and trainer offers), no name, no realm, no account.
